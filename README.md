# Прототип агропідприємства

Навчальний консольний прототип демонструє сезонні сценарії агропідприємства та зберігає технічні операції поля у SQLite. Після запуску створюється статичний HTML-звіт із фактичними записами бази даних.

## Передумови

- JDK 21 або новіший
- Maven 3.x
- Доступ до Maven-репозиторію для завантаження залежностей під час першого збирання

## Перевірка та збирання

```sh
mvn test
mvn clean package
```

## Запуск

```sh
mvn exec:java
```

Застосунок створює файлову базу `target/agrofarm.db` та звіт `target/operations.html`. Звіт можна відкрити у браузері як локальний файл; вебсервер не потрібен. Очищення через `mvn clean` видаляє каталог `target`, зокрема локальну базу даних і звіт.
