# Імітаційний прототип агропідприємства

Навчальний консольний прототип демонструє сезонний цикл агропідприємства: агроном планує культури, механізатор моделює польову роботу, комірник обліковує врожай, а агроном переглядає порівняння врожайності. Дані існують лише в пам'яті під час запуску; фізичні операції та прогноз погоди не виконуються, зовнішні залежності й мережа не потрібні.

## Передумови

Потрібен JDK 21 або новіший із командами `javac` і `java` у `PATH`. Команди нижче виконуються з кореня репозиторію в POSIX-сумісній оболонці.

## Компіляція та перевірки

```sh
mkdir -p out
javac --release 21 -encoding UTF-8 -d out $(find src/main/java src/test/java -name '*.java')
java -cp out agrofarm.PrototypeChecks
```

Перевіряльник завершується з кодом 0, якщо бізнес-правила виконуються; у разі помилки він завершується через `AssertionError`.

## Демонстрація

```sh
java -cp out agrofarm.DemoMain
```

Демонстрація автоматично, без введення користувача, послідовно показує планування культури, завершення польової роботи, облік урожаю та порівняння врожайності полів за сезон. Детальні очікування наведено у [quickstart.md](specs/002-agrofarm-prototype/quickstart.md).
