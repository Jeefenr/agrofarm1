# Перевірка та запуск

## Передумови

- JDK 21 або новіший, Maven 3.x, доступні через `PATH`.
- Виконання команд із кореня репозиторію.
- Зовнішня база даних або вебсервер не потрібні.

## Автоматизовані перевірки

```sh
mvn test
```

**Очікувано**: Maven компілює проєкт для Java 21 та завершує автоматичні unit/integration-перевірки успішно. Тести мають охоплювати чинні сценарії, стабільні ID, UPSERT без дублікатів, читання з файлу після повторного відкриття, пусту БД, безпечне HTML-екранування та політику часткових помилок.

## Збирання й наскрізний запуск

```sh
mvn clean package
mvn exec:java
```

**Очікувано**:

- Наявні сценарії виконуються у незмінному порядку з українськими повідомленнями.
- Застосунок створює `target`, якщо його ще немає.
- Файли `target/agrofarm.db` і `target/operations.html` створені.
- Таблиця звіту збігається з усіма записами БД; повторний запуск зберігає стабільну кількість рядків і оновлює записи з тими самими ID.

## Перегляд звіту

Відкрити `target/operations.html` у браузері як локальний файл.

**Очікувано**: сторінка відображає ідентифікатор операції, тип, стан та ID поля. Для порожньої бази є порожній стан; для часткової помилки запису є помітне попередження, а наявні в БД дані залишаються видимими. Атрибути з HTML-символами відображаються як звичайний текст.

`mvn clean` видаляє `target` разом із локальними даними та звітом; повторний запуск створює їх знову.

Архітектурні типи та правила наведені в [data-model.md](data-model.md), а консольні й HTML-вимоги — у [контракті](contracts/console-and-report.md).
