# Контракт запуску та статичного звіту

## Запуск консолі

- Точка входу: `agrofarm.DemoMain`.
- Запуск без інтерактивного введення; наявні демонстраційні сценарії виконуються в поточному порядку.
- Наявні україномовні консольні повідомлення та їхній порядок не змінюються.
- Помилки створення `target`, читання чи збереження даних повідомляються українською; помилка не супроводжується повідомленням про успіх.
- Невдала спроба запису однієї операції не перешкоджає спробі зберегти наступні операції.

## Контракт збереження

Застосунок використовує `target/agrofarm.db`. Для кожної технічної операції зберігаються її стабільний ID, тип, стан і ID поля-власника. Конфлікт стабільного ID означає оновлення запису. Видалення `target` видаляє БД і звіт; наступний запуск створює каталог та нову БД.

## Контракт HTML-звіту

- Шлях: `target/operations.html`.
- Формат: самодостатній статичний HTML; вебсервер не потрібен.
- Джерело рядків: усі фактичні записи, повернуті читанням SQLite після спроб збереження поточного запуску.
- Відображувані атрибути: ID операції, тип, стан і ID пов'язаного поля.
- Порожня БД: показати зрозуміле повідомлення про відсутність записів і не створювати вигаданих рядків.
- Невдалі записи: при успішному читанні показати доступні рядки й помітне попередження про помилки.
- Невдале читання: файл успішного звіту не створюється; помилка явно повідомляється в консолі.
- Значення атрибутів вставляються як екранований текст, а не як активна HTML-розмітка.
