# Перевірка і запуск імітаційного прототипу

## Передумови

- Встановлений JDK 21 або новіший і доступні `javac` та `java` у `PATH`.
- POSIX-сумісна оболонка з кореня репозиторію.
- Залежності, база даних і мережевий доступ не потрібні.

## Компіляція та перевірки

З кореня репозиторію виконайте:

```sh
mkdir -p out
javac --release 21 -encoding UTF-8 -d out $(find src/main/java src/test/java -name '*.java')
java -cp out agrofarm.PrototypeChecks
```

**Очікувано**: компіляція завершується без помилки; перевіряльник завершується з кодом 0. Будь-яка невдала умова завершує перевірку помилкою.

`PrototypeChecks` перевіряє допустимі та відхилені переходи польової роботи, відсутність прогнозу, належність операції полю, додатність і дедуплікацію надходжень, незмінність суми після відмови та сезонний аналіз із даними й без них. Повний перелік сутностей і обмежень наведено в [data-model.md](data-model.md).

## Наскрізний сценарій

```sh
java -cp out agrofarm.DemoMain
```

**Очікувано**: програма автоматично й без введення користувача демонструє планування культури, виконання польової роботи, облік урожаю та порівняння врожайності за полями. Повідомлення українською; зовнішні операції лише моделюються. Деталі користувацького інтерфейсу наведені у [контракті консолі](contracts/console-demo.md).
