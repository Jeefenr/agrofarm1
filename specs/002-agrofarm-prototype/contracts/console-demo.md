# Контракт консольної демонстрації

## Призначення

Описати спостережувану взаємодію навчального прототипу через консоль. Це контракт користувацького інтерфейсу, а не мережевий API.

## Запуск

- Точка входу: `agrofarm.DemoMain`.
- Демонстрація запускається без обов'язкових аргументів командного рядка та без інтерактивного введення.
- Один запуск відтворює один фіксований сценарій із прикладними даними.
- Середовище виконання: JDK 21 або новіший; зовнішні служби й мережа не потрібні.

## Поведінка й порядок

У повідомленнях має бути зрозуміло розрізнено:

1. планування культури для конкретного поля та сезону;
2. планування і завершення польової роботи;
3. результат обліку врожаю;
4. аналіз урожайності за полями вибраного сезону.

Текст, призначений користувачеві, виводиться українською мовою. Успіх, відмова через невалідні/повторні дані та відсутність даних мають відображатися як різні результати, а не як успіхоподібні повідомлення.

## Межі ефектів

- Повідомлення про польову чи складську операцію не означає виконання фізичної дії.
- Погода є модельованою; за її відсутності це прямо повідомляється, без запиту до зовнішнього сервісу.
- Стан і дані живуть лише в пам'яті поточного процесу; прототип не записує бізнес-дані у файл і не зберігає їх між запусками.
- Невалідні надходження не змінюють сезонну суму; відсутність врожаю не перетворюється на нульовий аналіз.

## Перевірка контракту

Запустити `agrofarm.DemoMain` за командами у [quickstart.md](../quickstart.md). Очікуваний запуск завершується без запитів до користувача, виводить увесь сезонний цикл українською та не потребує мережі. Детальні негативні випадки виконуються тестовим перевіряльником.
